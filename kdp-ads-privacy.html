Privacy Notice

For KDPbro, a private application that manages its owner's own Amazon Advertising campaigns through the Amazon Ads API.

What this application is

KDPbro is a single-user tool. It is operated by, and only by, the owner of the Amazon Advertising account it connects to. It is not sold, offered, licensed, or made available to anyone else, and it does not act on behalf of any third-party advertiser.

What it accesses

Using the advertising::campaign_management scope, and only for the owner's own advertising account, it reads:

  • advertising profiles and account identifiers
  • campaigns, ad groups, keywords, negative keywords and product ads
  • performance reports: impressions, clicks, spend, orders and sales

It writes only to those same campaigns: bid changes, budget changes, pausing and enabling, and adding keywords or negative keywords.

What it does with the data

Performance figures are used to calculate metrics such as advertising cost of sale, click-through rate and cost per click, and to apply the owner's own rules for bid and keyword changes to the owner's own campaigns. Nothing else.

Where the data is stored

On the owner's personal computer. Reports and campaign snapshots are written to local files. Access credentials, meaning the client identifier, client secret and refresh token, are stored in a file in the owner's user profile directory. None of this is uploaded to any hosted service, and none of it is committed to version control.

What is never done

  • No data is sold, rented, shared, or transferred to any third party.
  • No advertising data belonging to any other advertiser is requested or accessed.
  • No data is used to train models or build audience products.
  • This page sets no cookies, runs no scripts, and collects nothing from visitors.

Retention, revocation and deletion

Data is kept only while it is useful for managing the campaigns, and is deleted by removing the local files. Authorization can be withdrawn at any time from the Amazon account that granted it, under Login with Amazon permissions at amazon.com/ap/adam. Revoking access immediately stops the application from reading or changing anything.
